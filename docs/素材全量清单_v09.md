## 4. 核心难点：动作流畅 + 运动不变形

这是本次需求里最难的部分。技术方案：

### 4.1 不变形（Anti-distortion）

| 措施 | 做法 | 防止的问题 |
|---|---|---|
| **union bbox 统一裁剪** | 同一动作所有帧取并集包围盒，再统一缩放 | 帧间抖动、肢体伸缩 |
| **固定锚点** | 每帧底部中心对齐，脚底基线固定 | 行走时人物上下跳 |
| **禁止单帧独立生成** | 多帧一律 img2img 从基准帧转 | 铁律 1："会变人" |
| **镜像而非重绘** | 右向 = 左向 PIL 镜像 | 镜像后光照不一致（需接受） |
| **尺寸锁定** | 角色全帧统一 384，杂兵 256 | 缩放比例不一致导致体型跳变 |

### 4.2 流畅度

| 措施 | 参数 |
|---|---|
| walk 帧数 | 从 4 帧 → **6 帧**（现有 4 帧偏少，循环有跳帧感） |
| 帧率 | walk 12 fps / idle 6 fps（Godot `SpriteFrames` 配置） |
| 循环首尾 | 末帧不与首帧重复，避免顿挫 |
| 特效帧数 | 命中 6–8 帧、爆炸 10–12 帧、Boss 登场 16+ 帧 |

### 4.3 生成管线（严格顺序）

```
① 基准帧（txt2img 精修立绘，1 张定形象）
      ↓
② img2img 转 walk 帧序列（保持同一形象，指定同一锚点）
      ↓
③ PIL 镜像生成右方向
      ↓
④ union bbox 统一裁剪
      ↓
⑤ 统一缩放到目标尺寸 + 脚底基线对齐
      ↓
⑥ rembg 抠透明底
      ↓
⑦ 帧间配准校验（bounding box 尺寸方差超阈值则重出）
```

## 7. 已知技术坑（STYLE_GUIDE 血泪 + 本次实测）

| 坑 | 表现 | 对策 |
|---|---|---|
| txt2img 不吃 `negative_prompt` | HTTP 400 | 禁忌词写进 prompt 正文 |
| 主体带场景背景 | 6/6 样品全带场景 | prompt 强调 `isolated, no background scenery` + 后期 rembg |
| tile 出成网格 atlas | 反复出现 | `NO grid lines, NOT a tileset atlas` + 多次重试 + 后期无缝化 |
| 多帧独立文生图 | 人物变形 | 铁律 1：一律 img2img |
| rembg venv 不存在 | 沙箱内无 | 需安装 |
| Godot `Environment.glow` 在 GL Compatibility 下不生效 | 无辉光 | 走加色混合贴图（项目已有此方案） |
