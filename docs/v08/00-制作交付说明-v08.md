## 0. TL;DR

v0.7 框架完整可玩，但**招牌系统「超武合成」在代码层面近乎不可达**（被动获取被 4 条链锁死）。v0.8 方案已由工作室八名角色完成设计→架构→资产→实现→验收全链路编排：**9 批次、≈58.9 人日、QA 有条件通过且 7 条放行条件已全部修订闭环**。等一个决策：**启动编码**（全量五层），或先发布 **L0+L1 最小可玩层（≈25 人日）**。

## 1. 核心发现（为什么必须做 v0.8）

| 发现 | 证据 | 影响 |
| --- | --- | --- |
| 超武合成近乎不可达 | `player.gd:1051-1066` 选池算法 + 合成自锁(`:999`) + 升级预算 48>32 | 19 条超武路线成死系统，宣传口径无法兑现 |
| 局外经济断链 | 单局 303 金 vs 属性全满 34.5 万金（`meta.gd:321`） | ≈913 局才能全满 |
| 难度曲线锯齿 | `game_data.gd:391-398` 每 6 层断崖 −70% 血 | 体验振荡 |
| 58% 美术未接线 | 10 敌只接 4、12 遗物只接 4、Boss 分化/宝箱零引用 | 已付费资产闲置 |
| 四项结构性能问题 | `fx.gd:249` hitstop 压全局 5% 速度、零池化、每命中 new 材质、首包 52.9MB | 内容扩张前必须修 |

**合成率修正口径**（三画像蒙特卡洛，Phase 1 的 9.8% 作废）：定向玩家 **100%** / 休闲（50% 跟推荐）**47%** / 纯随机 **2.4%** 的局能合成 ≥1 把超武。

## 2. 决策记录

**用户拍板（4 项）**：三主题全要（构筑能成型+地牢有形状+活下去）｜平台继续 Web｜遗物 12 件全接｜放弃单文件 HTML 构建（解锁 gzip/brotli 压缩路径）。

**制作人裁决（7+1 项）**：推荐金框 UI 保留（A-1 硬判据成立）｜宝箱演出以 05 为准｜槽满替换弹窗 v0.8 不做｜fx_hit_spark.png 剔除出包留源文件｜supercharge 复用 superfuse 原语（参数以 06 为权威）｜被动 6 槽瓶颈 v0.8 保留、v0.8.5 备选｜排期按 14.3/11.5/25.8 执行｜A-6 判据以 01 终稿为权威（定向 48–62.7%）。

## 4. 各阶段产出汇编

### 4.1 设计 → 游有方（`01-design-v08.md`，终稿）
五层结构、每层可发布判据、砍单线；RC-1~4 根因链（选池算法主锁/池序/合成自锁/预算）；修复方案=加权抽取+漏斗×3+强制槽+保底，模拟验证被动槽位 41-59%、≥90% 的局能合成；12 遗物效果表（5 纯属性走 StatBlock+7 代码钩子）；武器槽规则 **W1-W4**（槽满自然移出/补权 22→30/不做换武器/漏斗保底不受影响，槽满瓶颈实测仅 3%）；验收标准 A-1~A-13。

### 4.2 架构 → 柯桥良（`02-architecture-v08.md`）
平台打分 Web 3.90 > Steam 3.60 > 移动 2.35；A1-A9 改造项（A3a 选择器 0.3d 阻塞 / A3b StatBlock 2.5d 随 L2）；性能预算：**30fps 底线 / 物理 ≤4ms / DC ≤250 / 同屏 ≤60 / 节点 ≤900 / 首包压缩后 ≤12MB（gzip 保底 14MB 分档，§7-H5）**；无头验证链已实测跑通（真实入口+autoload 驱动；`-s` 模式不可用）；死资产 12.3MB（含美术线新发现的 assets/enemy 与 divider_gold）。

### 4.3 资产四线（Phase 2）
- **美术 `03`**：零新增；12 遗物图标/3 新敌/Boss 分化贴图/chest 全部就绪合规；遗物 UI 零贴图缺口（StyleBoxFlat 代码画法，蓝 #6FB7D6 / 紫 #8E44AD / 金 #F0C060）；lobby_bg WebP q80 → ≤250KB；**建议 R2 开 brotli，否则 wasm 压不进 12MB**。
- **动画 `04`**：hitstop 改**白名单制**（9 类事件、全局冷却 0.15s、普攻移出全局顿帧）；演出全程序化补间不引入 AnimationPlayer；60 怪动画 ≈0.1ms/帧。
- **特效 `05`**：修 4 结构性问题（`fx.gd:297` 共享材质单例收益最大）；6 池 **164** 节点常驻、粒子 ≤650 红线 800 三级降级；最坏场景 DC 峰值 ≈234 ≤250；敌弹可读性三重保障；**文末「§附录：合成演出统一时间轴（权威版）」**为演出唯一时序依据。
- **音频 `06`**：双轨链路保留，收口为 `data/audio_manifest.json`+构建门禁（1.3d，现有 13 音色双写已漂移）；BGM 32kHz/64kbps 重编码 1.65→0.65MB 删 CDN 单点；Boss 动态音乐延后 v0.9，ducking 0.1d 替代。

### 4.4 实现 → 寇豆码（`07-implementation-v08.md`，已按 QA 修订）

## 6. 风险 Top 5

1. **R2 无 brotli** → 首包只能 ≈14MB（gzip），12MB 硬线失守（A7 落地时定案，gzip-only ≈22MB 无论如何先做）
2. **L4 寻路**是最大技术不确定项（10 人日中占比最高，砍单线第一刀）
3. **音频双写漂移**若不先收口 manifest，B1-B5 每批都在扩大漂移面
4. **9 项人工验收**无法自动化，真机清单（尤其低端机 30fps 底线）需提前约测
5. **player.gd 1520 行**串行合入约束（B2→B4→B5→B8）是关键路径，并行度受限
