## 📖 玩法

- **核心玩法**：割草生存。角色自动攻击，玩家只负责走位、构筑与合成。
- **角色差异在武器**：三名角色三把专武——艾拉（弓箭）、巴顿（斧头）、墨菲（法球），开局自带。
- **超武进化**：武器升满 + 指定被动升满，在三选一中合成超武，19 把武器 / 19 条合成路线。
- **四流派**：枪械 / 召唤 / 死灵 / 近战，各有独立武器与超武；角色只提供 15% 亲和加成，不绑定流派。
- **敌人节奏**：四种杂兵（史莱姆 / 蝙蝠 / 喷吐怪 / 蛮兽），每 5 分钟一只 Boss，撑满 30 层通关，通关后解锁无尽模式。
- **局内遗物**：独立 3 格，只从精英 / Boss / 宝箱掉落，12 件分蓝紫金三档。
- **技能**：2 槽（1 专属 + 1 通用池），默认自动释放可切手动，3 级满级。
- **局外成长**：结算金币用于永久属性强化、三系天赋树（战斗 / 生存 / 贪婪）与解锁新角色 / 新武器。
- **中途存档**:战斗中可一键存档回大厅，下次从大厅「继续冒险」接着打。

## 🛠 技术与制作说明

- **引擎**：Godot 4.7.2（GDScript），Web 导出 + 自定义 HTML 壳（`web/shell.html`：加载屏、BGM、原生 WebAudio 音效通道、浮动虚拟摇杆）。
- **🤖 由 Muse 驱动**：本项目的设计、编码、数值、调试、部署与迭代，全部由 Meta 的个人 AI 智能体 **Muse** 在与开发者的对话中完成——从玩法定稿到每一行 GDScript、每一次导出与上线验证，均由 Muse 直接执行。
- **🎨 素材来源 Agnes**：角色立绘与精灵、怪物、地牢贴图、火把火焰、大厅背景等美术素材，由 **Agnes AI**（文生图 / 图生图）生成，再经抠图、逐帧切片与程序化后处理接入游戏；少量环境装饰（火把托架、裂纹地面等）由代码程序化生成。
- **音频**：BGM 为 CC0 环境音乐（OpenGameArt）；音效由代码程序化合成（Web 端走原生 WebAudio，绕过引擎音频管线）。

## 📁 项目结构

```
scripts/    游戏逻辑（主循环 / 大厅 / HUD / 角色 / 敌人 / 存档等）
scenes/     Godot 场景
assets/     美术与音频素材（Agnes 生成 + 后处理）
web/        自定义 Web 导出壳 shell.html
tools/      素材后处理与单文件打包脚本
test/       引擎内截图 / 存档验证脚本
```

## 🚀 本地运行

1. 安装 Godot 4.7.2，导入本工程打开 `project.godot` 即可运行。
2. Web 导出使用 `export_presets.cfg` 中的 Web 预设，导出壳为 `web/shell.html`。
