# 图像生成工作流

> 本专家可**直接生成图像**。本文件规定什么时候生成、怎么生成、生成后怎么处理。

## 一、先判断：该生成，还是该评审 / 给建议

| 用户的诉求 | 正确动作 |
|---|---|
| 「这张图哪里有问题」 | **只评审**，不重画（除非用户要求重画） |
| 「帮我画一个 XX」 | 生成 |
| 「风格对不对」 | 先评审 + 给锚点，锚点确认后再生成 |
| 「还差什么资源」 | 先盘点清单，再按批次生成 |
| 「换一批试试」 | 生成新版本，**保留旧版本**（`@v2`），不覆盖 |

**铁律**：风格锚点未确认时**不批量生成**。先生成 1–2 张基准图给用户确认。

## 二、生成前的必填四项

1. **风格锚点**（没有就先定，见 `style-control.md`）
2. **尺寸**（画布宽 × 高，2 的幂优先）
3. **用途**（角色 / 怪物 / 场景 / UI / 图标 / 特效）
4. **朝向**（默认只做单方向 + 代码镜像）

缺任何一项，先问。

## 三、生成参数约定

| 参数 | 约定 |
|---|---|
| 尺寸 | 按规格表；UI 与图标可直接出目标尺寸，角色/怪物**出 2 倍尺寸再缩**（缩小的边缘更干净） |
| 质量 | 定稿候选用高质量；探索风格阶段用标准质量，省成本 |
| 背景 | **纯色底**（抠图友好），不使用渐变背景 |
| 数量 | 同一提示词一次只出 1–2 张，选定方向后再批量 |

## 四、交付双版本

| 版本 | 说明 | 命名 |
|---|---|---|
| **纯色底版** | 生成原图，用于复核与再次处理 | `<资产名>@v1_src.png` |
| **透明底版** | 抠图后可直接入图集 | `<资产名>@v1.png` |

转透明底：
```bash
python art_asset_tools.py keyout <src.png> --color "#FF00FF" --out <资产名>@v1.png
```
脚本会自动：去除指定底色（带容差）、裁掉四周多余透明边、报告保留的主体像素数与边缘杂色情况。

**两个安全护栏（避免拿到坏产物却不知道）**：
- **整图被判为底色时报错、不写文件**（退出码 3）—— 说明 `--color` 取错了或 `--tol` 太大，先用 `palette` 取背景色再重试；
- **`--tol` 不接受负数**（退出码 1）—— 负容差会被平方成正数、静默等价于正容差。

**写盘前会提示是否覆盖已存在的同名文件**，避免无意中覆盖上一版产出。

## 五、生成后必须做的事

1. **规格校验**：
   ```bash
   python art_asset_tools.py check <dir>
   ```
   检查命名规范、尺寸、格式、透明边残留、边缘杂色，并输出产出清单。
2. **缩略图测试**：`python art_asset_tools.py sheet <dir>` 生成接触表，缩小看是否认得出。
3. **一致性比对**：与同族已有资产并排比对（线宽、比例、光照方向、辅色）。
4. **标注**：在文档中记录**该图由 AI 生成**、版本号、关键提示词与参数。

## 六、精修判定（必须诚实标注）

| 生成结果 | 判定 | 处理 |
|---|---|---|
| 剪影、风格、规格均达标 | **可直接使用**（仍需合规确认） | 入图集 |
| 剪影达标，边缘 / 明度有瑕疵 | **需轻修** | 修边、调明度（脚本可做一部分） |
| 剪影不达标或风格漂移 | **需重做** | 改提示词或走降级方案 |

**禁止谎报"可直接商用"**。AI 生成图必须经人工精修与合规确认，我会在交付时明确写出哪些需精修、哪些已达标。

## 七、版权与合规红线

- ❌ 不生成、不"换个颜色规避"受版权保护的角色与 IP 形象；
- ❌ 不指定模仿在世艺术家的个人风格；
- ❌ 不生成含真实品牌标识、真实人物肖像、水印的内容；
- ✅ 用户给受保护 IP 作参考时，指出风险 + 给原创替代方向（提取结构特征，替换形象设计）；
- ✅ 生成图中若出现疑似文字 / 签名，视为缺陷，重新生成或裁掉。

## 八、产能提示

- **一次一行**：同时改多个变量会导致失败原因不可归因；
- **先调好一张**：基准图定稿前不要批量，批量返工成本是单张的十倍；
- **代码能做的别生成**：同形状只变色/变尺寸的（稀有度边框、血条、状态色）交给代码；
- **探索阶段省成本**：定风格用低规格多方案，定稿才出高规格。
