# 风格把控与色彩规范

## 一、风格锚点（一段话，逐字复用）

风格锚点是**唯一风格来源**。写出来后，所有提示词与评审都以它为依据，不允许"这次先这样"。

```
【风格锚点 v1】
画风：<如 2D 手绘卡通 / 像素 / 国风水墨剪影 / 厚涂写实>
视角：<正交侧视 / 45° 俯视 / 正面三分之四>
光照：<左上主光 + 暖色补光 / 月光冷调背光 / 无方向平光>
线宽：<统一 3px 手绘描边，外深内浅>
质感：<哑光平涂 + 少量手绘笔触，无高光反射>
比例：<Q 版三头身，头部占整体 40%>
色彩倾向：<低饱和暖色为主，冷色仅用于阴影与背景>
禁忌：<不出现在世艺术家的个人风格；不用渐变光晕；不写实解剖>
```

**检查项**：禁忌必须写，否则后续生成会漂。

## 二、色彩板

| 角色 | 用途 | 色号（示例，实际以项目锚点为准） | 明度 |
|---|---|---|---|
| 主色 | 主角 / 主按钮 | `#C97B3A` | 高 |
| 辅色 | 次要元素 | `#5A6B4A` | 中 |
| 强调色 | 交互反馈 / 高亮 | `#E8EDF2` | 最高 |
| 危险色 | 伤害 / 警告 | `#C0392B` | 高 + 高饱和 |
| 背景色 | 场景底色 | `#39485A` | 低（比主体低 ≥ 2 档） |
| 阴影色 | 统一暗部 | `#141A20` | 最低 |

**硬规则**：
1. **主体与背景必须落在不同明度区间**（至少差 2 档），否则缩略图下必然糊；
2. 同屏出现超过 3 种高饱和色 = 视觉噪音，压掉多余的；
3. 同族对象（同一类怪物）**共用同一组辅色**，只换主色区分个体；
4. 色号写进规格文档，不允许"凭感觉调"。

**提取现有资产色板**：`python art_asset_tools.py palette <图> --top 8` 可直接拿到主色与占比，用于对齐已有资产。

## 三、明度阶梯（比色相更重要）

| 层级 | 明度区间（L，0–100） | 用途 |
|---|---|---|
| 高光 | 80–95 | 金属 / 水面 / 强调 |
| 主体亮面 | 60–80 | 受光面 |
| 主体中间调 | 40–60 | 固有色 |
| 主体暗部 | 20–40 | 背光面 |
| 背景 | 10–35 或 75–90 | 与主体错开 |
| 阴影 / 描边 | 5–20 | 统一轮廓 |

**验证方法**：把成品图转灰度，若主体与背景仍清晰可分，明度层级就是合格的。

## 四、一致性检查（三道）

| 检查 | 做法 | 不合格处理 |
|---|---|---|
| **同族比对** | 同一类怪物全部排在一张图上看 | 统一线宽、比例与辅色 |
| **同对象状态比对** | 常态 / 受击 / 攻击 三态并排 | 统一光照方向与描边策略 |
| **跨类别比对** | 角色 + 场景 + UI 同屏拼一张 | 统一色彩倾向与质感，避免 UI 比角色更抢眼 |

**工具**：`python art_asset_tools.py sheet <dir>` 生成接触表，正是为这三道检查服务的。

## 五、迭代收敛机制

用户反复迭代时，最容易出的问题是**改了这个忘了别的 / 已确认的又被改回去**。固定流程：

1. **版本号**：每次迭代 `@v1` → `@v2`，**旧版保留**（供回溯对比）。
2. **只改指定部分**：用户说"只调头部比例"，就只动头部；不得顺手改配色或线宽。
3. **已确认项冻结**：风格锚点中已确认的条目，未经明确要求**不得变更**；确需变更时先说明"这会推翻之前哪几项"。
4. **变更记录**：每次改完记录「改了什么 / 为什么 / 影响哪些已产出资产」。
5. **收敛判据**：连续两轮用户无实质修改意见 → 视为定稿，写入风格锚点版本号并冻结。

> 一条经验：**先调好一张，再推进下一张**。批量生成 20 张再来回改风格，成本是单张迭代的十倍。

## 六、参考图使用方式

| 用户给的参考 | 正确用法 | 禁止 |
|---|---|---|
| 某款游戏截图 | 提取**结构性特征**（视角、光照、比例、色彩区间）写成锚点 | 直接仿画该游戏的角色或场景 |
| 某位画师作品 | 提取可描述的技法（线宽、笔触、明度处理） | 指定"模仿某画师个人风格" |
| 受版权保护的 IP 形象 | 指出风险，给原创替代方向 | 生成或"换个颜色"规避 |

**参考图定位**：参考图是**需求沟通工具**，不是生成目标。锚点才是我要复现的东西。
