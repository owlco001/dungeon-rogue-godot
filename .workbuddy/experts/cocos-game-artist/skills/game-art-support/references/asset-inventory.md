# 资产清单与规格规范

## 一、资产分类（固定七类）

| 类别 | 说明 | 常见子类 |
|---|---|---|
| 角色 | 玩家 / 主角 | 常态、行动、受击、特效叠加层 |
| 怪物 | 敌人 / NPC | 按族分组，各族 1 个基准 + 变体 |
| 场景 | 地图 / 背景 / 瓦片 | 地表、装饰、可交互物、前景遮挡 |
| UI | 界面控件 | 按钮（常态 / 按下 / 禁用）、面板、进度条、弹窗底 |
| 图标 | 功能与道具 | 道具、技能、货币、状态图标 |
| 特效 | 打击 / 反馈 | 命中、爆炸、升级、光效 |
| 字体 | 文字表现 | 标题字、正文字、数字、描边 |

## 二、命名规范（建议统一为四段式）

```
<类别>_<对象>_<变体或状态>@v<版本>
例：mon_boar_normal@v2.png
    ui_btn_primary_pressed@v1.png
    fx_hit_slash_small@v3.png
```

| 段 | 取值要求 |
|---|---|
| 类别 | 固定前缀：`char` / `mon` / `env` / `ui` / `icon` / `fx` / `font` |
| 对象 | 小写英文 + 下划线，不用中文与空格 |
| 变体或状态 | `normal` / `attack` / `hurt` / `pressed` / `disabled` / 尺寸档（`small` / `large`） |
| 版本 | `@v1` 起步，每次迭代 +1；**旧版本不删，改名加 `_deprecated`** |

**禁止**：`新建文件夹`、`未命名-1`、`最终版`、`最终版2`、`改过的`。

## 三、资源规格表（每个资产必填）

| 字段 | 说明 |
|---|---|
| 资产名 | 按命名规范 |
| 类别 | 七类之一 |
| 用途 | 出现在哪个界面 / 玩法环节 |
| 画布尺寸 | 宽 × 高（px），2 的幂优先 |
| 画布比例 | 统一同族比例（如角色统一 1:1 画布） |
| 格式 | PNG（需透明）/ JPG（不透明大图）/ WebP（按平台支持） |
| 透明底 | 是 / 否；是则要求四周无残留杂色 |
| 朝向 | 只做单方向 + 代码镜像（省一半产能） |
| 图集分组 | 归到哪个图集（同屏同时出现的归同组） |
| 优先级 | P0 玩法必需 / P1 应有 / P2 有余力 |
| 状态 | 未开始 / 提示词就绪 / 已生成待修 / 已定稿 |

## 四、缺口清单（盘点产出）

```markdown
| # | 资产 | 类别 | 规格 | 用途 | 优先级 | 状态 | 阻塞什么 |
|---|---|---|---|---|---|---|---|
| 1 | char_hero_idle | 角色 | 256×256 PNG 透明 | 主界面 | P0 | 未开始 | 核心循环无法验收 |
```

**盘点规则**：
- 优先级只按**玩法依赖**定，不按"好不好看"定；
- P0 = 缺了玩法无法验收；P1 = 缺了体验明显下降；P2 = 锦上添花；
- 每个 P0 必须写清"阻塞什么"，用来排期。

## 五、产出批次与顺序

**按"能被一套锚点覆盖"分批**，而不是按类别分批：

| 批次 | 内容 | 目的 |
|---|---|---|
| 第 1 批 | 1 个角色 + 1 个怪物的**基准图** | 敲定风格锚点与线宽（**只出 1–2 张**） |
| 第 2 批 | 同类变体 + 动作状态 | 验证锚点可复用 |
| 第 3 批 | 场景与瓦片 | 验证与角色是否同族 |
| 第 4 批 | UI 与图标 | 验证在界面上的表现 |
| 第 5 批 | 特效 | 最后做，依赖前四批定稿 |

> **不要一次性排 60 张**。第 1 批定稿前，后面的规格随时会变，做出来就是返工。
