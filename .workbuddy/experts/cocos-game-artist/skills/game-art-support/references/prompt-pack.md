# 提示词包方法论

> 目标：**同一批 / 跨批生成的图必须是同一套东西**。靠的是把风格部分**逐字冻结**，只让变量部分变化。

## 一、提示词包的四段结构（顺序固定）

```
【风格锚点】← 逐字复用，一个字都不改
【主体描述】← 每次换（本张画什么）
【画布与构图】← 尺寸、朝向、留白、居中要求
【技术约束】← 纯色底、不透明、无文字、边缘干净
```

**关键**：把「风格锚点」单独存成一个文本块，每次生成**整段复制粘贴**，不要凭记忆重写。凭记忆改写 = 风格漂移的头号原因。

## 二、变量槽位表（批量生成用）

| 槽位 | 取值示例 | 更换频率 |
|---|---|---|
| `{对象}` | 野猪 / 蝙蝠 / 树精 | 每张换 |
| `{类别}` | 怪物 / 角色 / 道具图标 | 每批换 |
| `{状态}` | 常态 / 受击 / 攻击 | 每状态换 |
| `{主色}` | `#8B5A2B` | 同族内换 |
| `{尺寸}` | 512×512 | 同族固定 |
| `{朝向}` | 朝右 | **全项目固定** |

**规则**：一次只变一个槽位。同时改主色 + 尺寸 + 朝向 → 出问题时分不清是哪个变量导致的。

## 三、可抠图性（最重要的一条工程要求）

游戏资产需要**透明底**才能入图集。生成时的硬约束：

1. **纯色底**：指定单一高对比底色（如 `纯白背景` 或 `纯品红 #FF00FF 背景`），**不要渐变、不要阴影投射到背景、不要背景元素**；
2. **边缘干净**：明确要求 `轮廓清晰、无外发光、无半透明边缘`——外发光会直接破坏抠图；
3. **主体不贴边**：四周留 8–10% 安全边距，否则裁切时会被切到；
4. **双版本交付**：同一张图**同时产出纯色底版与透明底版**：
   - 纯色底版 = 生成结果（可再生成 / 可复核）
   - 透明底版 = `python art_asset_tools.py keyout <img> --color "#FF00FF"` 转出

> 不要把"生成的图"直接当最终素材用。先生成纯色底 → 抠图 → 修边 → 入图集，这条链路才是可复现的。

## 四、朝向：只出单方向 + 代码镜像

- **全项目只做一个朝向**（如朝右），需要左向时在引擎里水平翻转；
- 例外：**有明显不对称特征的对象**（独眼、单手持武器、文字标识）必须左右各出一版，否则镜像后会出现"反手拿刀"；
- 上下方向同理：俯视 45° 的对象如果要做旋转动画，需出多方向（此时不是镜像能解决的，要在资产清单里单列）。

## 五、三级降级方案（生成不出预期时，按顺序退）

| 级别 | 做法 | 适用 |
|---|---|---|
| 一级 | **改提示词描述**：把抽象词换成可执行描述（"高级感" → "哑光平涂 + 冷色轮廓光"） | 首选，成本最低 |
| 二级 | **简化主体**：减少细节与配件，先保证剪影成立 | 描述改了两轮仍不理想 |
| 三级 | **拆件生成**：主体与配件分开生成，后期合成；或改由人工按规格精修 | 复杂对象 / 生成能力明显不匹配 |

**禁止**：反复重试同一提示词超过 3 次（属于赌博，不是方法）。

## 六、生成后自检清单（每张必过）

- [ ] 背景是纯色、无渐变、无投影
- [ ] 主体四周有安全边距，未被裁切
- [ ] 无外发光 / 半透明边缘（抠图友好）
- [ ] 与风格锚点的**线宽、比例、光照方向**一致
- [ ] 缩小到 10% 仍能认出主体（缩略图测试）
- [ ] 转灰度后主体与背景明度可分
- [ ] 尺寸符合规格表，非放大凑尺寸
- [ ] 无文字、无签名、无水印、无可识别的品牌元素
- [ ] 不包含受版权保护的角色特征

## 七、程序化叠加（省产能的补充手段）

有些装饰**不该靠生成，该靠代码**：

| 需求 | 做法 |
|---|---|
| 统一描边 | 生成无描边版本，引擎侧加描边材质 / 用脚本批量描边 |
| 稀有度边框 | 生成框体底图，颜色与光效由代码叠加（一套框体 N 种稀有度） |
| 血条 / 进度 | 生成底图与填充条，长度由代码控制 |
| 状态特效 | 生成静态贴图，位移 / 缩放 / 透明度由代码做 |

> 判断标准：**同一形状只变颜色或尺寸** → 交给代码，不要生成 N 张。

## 八、与既有技能的关系

若当前环境已安装 `game-art-prompt-pack` 技能，其方法论与本文件一致，可叠加使用；本文件是自带的最小可用版本，保证本专家在任何环境下都能独立工作。
