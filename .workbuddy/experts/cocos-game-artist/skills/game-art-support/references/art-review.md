# 美术评审规范

> 评审的目的不是挑刺，是让作者知道**下一步改哪里、改成什么样**。写不出具体改法的，不算问题。

## 一、单图评审：六维度打分（每项 1–5 分）

| 维度 | 5 分标准 | 常见扣分项 |
|---|---|---|
| **剪影可读性** | 涂黑后仍能认出是什么，缩小到 10% 依然清晰 | 轮廓被内部细节干扰、四肢与主体糊在一起、武器/尾巴与身体同色 |
| **明度层级** | 主体 / 次体 / 背景三段分明，转灰度仍分得清 | 主体与背景明度接近、全图挤在中间调 |
| **构图与负空间** | 视觉重心明确，留白合理，关键部位未被裁切 | 主体贴边、头顶被裁、留白平均分配无主次 |
| **风格一致性** | 与项目已确认资产的线宽、比例、色彩、质感同族 | 线宽忽粗忽细、头身比不同、色调偏冷偏暖不统一 |
| **技术合规** | 尺寸正确、格式正确、无透明边残留、无边缘杂色、非放大凑尺寸 | 边缘一圈白/黑边、透明区有半透明脏点、实际分辨率低于标注 |
| **可用性（UI 类）** | 点击区够大、文字对比度达标、状态可辨 | 按钮可点区小于视觉区、文字与底色对比不足、禁用态与常态难区分 |

**缩略图测试（必做）**：把图缩到 10%、25% 各看一次；
- 10% 认不出主体 → 剪影或明度有问题，**重做**；
- 25% 认得出但细节糊 → 正常，属可用范围。

**结论分档**：

| 分档 | 判据 | 处理 |
|---|---|---|
| ✅ **通过** | 全部维度 ≥ 4，无技术合规问题 | 可入图集 |
| ⚠️ **小改** | 剪影与风格合格，问题集中在明度 / 边缘 / 对比度 | 不改结构，只调色与修边 |
| ❌ **重做** | 剪影认不出、或风格不同族、或靠放大凑尺寸 | 重做，并先回风格锚点确认 |

## 二、批量评审（一批资源 / 整个目录）

在单图评审之外，追加四项系统性检查：

| 检查 | 看什么 | 输出 |
|---|---|---|
| 命名一致性 | 是否符合项目命名规范（见 `asset-inventory.md`） | 需重命名的清单 |
| 规格一致性 | 同族资产尺寸 / 画布比例 / 朝向是否统一 | 规格异常清单 |
| 重复与冗余 | 是否有同功能重复资产、是否有废弃未用资产 | 可合并 / 可删除清单 |
| 缺口盘点 | 玩法需要但还没有的资产 | 缺口清单 + 优先级 |

**工具**：`python art_asset_tools.py check <dir>` 会自动查命名、尺寸、格式、透明边残留与边缘杂色，并输出产出清单；`sheet` 生成接触表用于批量缩略图测试。

> **透明通道的判定规则**：只有 `char` / `mon` / `ui` / `icon` / `fx` / `font` 这几类资产要求带透明通道；`env`（场景 / 背景）允许不透明，不会被报为缺陷 —— 否则合法的背景图会被误判。
> **`trim` 会保留子目录结构**，不同子目录下的同名文件不会互相覆盖。

## 三、评审报告格式

```markdown
## 评审结论
总体：⚠️ 小改（3 张通过、5 张小改、1 张重做）

## 问题清单
| # | 资产 | 维度 | 问题 | 为什么是问题 | 具体改法 | 优先级 |
|---|---|---|---|---|---|---|
| 1 | slime_normal.png | 明度 | 主体与背景明度差 < 15% | 缩略图下主体糊成一团 | 背景压暗一档（明度 −20），主体边缘加 1px 深色描边 | P0 |

## 需精修项
（列出 AI 生成但需人工精修的地方）

## 建议推进顺序
1. 先修 P0 的明度与剪影问题 → 再统一线宽 → 最后批量修边
```

**硬要求**：
- 每条问题必须能回答「改成什么样」（给数值、色号或具体操作）；
- 按优先级排序，P0 = 影响可读性或无法入图集；
- 涉及风格判断的，必须**引用风格锚点原文**作为依据，而不是个人偏好。

## 四、常见的"看起来不舒服"根因表

| 主观感受 | 大概率根因 | 改法方向 |
|---|---|---|
| 糊、看不清 | 明度层级不足 / 细节噪声多 | 拉大明度差、减少内部细节、加轮廓光或描边 |
| 拼凑感 | 线宽或比例不统一 | 统一线宽与头身比，统一描边策略 |
| 太脏 | 饱和度与明度同时偏高、环境色过量 | 降饱和、统一光源方向、减少杂色 |
| 平 | 缺少明度梯度与材质对比 | 加高光与暗部、区分材质反射 |
| 挤 / 闷 | 留白不足、主体过大 | 扩画布留白、缩小主体、调整视觉重心 |
| 不像同一套 | 色彩倾向不一致 | 统一到色彩板，用同一组辅助色 |
